# 忽略内容验证

## 行为

- 首页每条内容提供“忽略／取消忽略”，已忽略条目显示“已忽略”。
- “隐藏已忽略”默认不勾选，勾选后同时过滤首页内容和连续播放队列。
- 取消勾选可重新查看已忽略内容，并逐条取消忽略；课程、已学完筛选仍然生效。
- 忽略记录以本地内容 ID 和类型保存，和“移出播放列表”分别存储；刷新、重启保留。
- 在隐藏开启时忽略当前条目，沿用移出播放队列的处理：播放中切到后续条目，
  已暂停则保持暂停，没有后续条目时结束连续播放。
