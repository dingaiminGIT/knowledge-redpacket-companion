# 忽略内容验证

## 行为

- 首页默认只保留播放；左滑每条内容露出“忽略／取消忽略”，或长按打开操作菜单。
- 滑到底也不会自动执行；短滑回弹，右滑、上下滚动和点击外部可收起。
  收起操作区的点击不会继续触发播放，同一时间只展开一条。
- 已忽略条目显示“已忽略”；忽略和取消忽略后提供“撤销”，默认显示 8 秒，
  按系统无障碍操作时限延长；提示消失后仍可通过已忽略内容恢复。
- 首次使用显示滑动／长按提示，并为读屏提供“忽略／取消忽略”自定义动作。
- “隐藏已忽略”默认不勾选，勾选后同时过滤首页内容和连续播放队列。
- 取消勾选可重新查看已忽略内容，并逐条取消忽略；课程、已学完筛选仍然生效。
- 忽略记录以本地内容 ID 和类型保存，和“移出播放列表”分别存储；刷新、重启保留。
- 在隐藏开启时忽略当前条目，沿用移出播放队列的处理：播放中切到后续条目，
  已暂停则保持暂停，没有后续条目时结束连续播放。
