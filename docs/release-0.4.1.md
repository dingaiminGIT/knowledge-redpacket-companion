# 知识红包伴侣 0.4.1

2026-11-05 发布，versionCode 16。沿用 0.4.0 签名，可覆盖安装并保留缓存与设置。

- 修复播放中断后连播监控未恢复，导致末尾停住、不进入下一条的问题。
- 同一受控内容实际恢复播放时重新启用监控；末尾暂停直接衔接下一条，不等待原内容重播。
- 保留主动暂停和官方换课保护；外部改播其他内容时让出播放控制。
- 暂停确认前重读最新进度，补充暂停时间、位置和恢复诊断。
- 包含左滑或长按忽略、撤销、隐藏已忽略及红包到期日显示。

45 项单元测试、Android 构建和 Lint、页面导航脚本回归通过。
真机已验证 11:52 / 11:53 的 PAUSED 状态衔接下一条、短时息屏衔接、主动暂停及外部换课。

手机测试只允许使用测试前已学完的内容，并检查所有自动续播后继条目，避免改变用户未学完内容的进度。
